# VS-code-scripts

A place to keep my scripts created in VS code which aren't specific to any of the individual repositories already within GitHub.

## Purpose

This repository serves as a central location for storing general-purpose scripts, utilities, and tools that are useful across multiple projects but don't belong to any specific repository.

## Structure

```
VS-code-scripts/
├── scripts/         # General-purpose scripts
├── templates/       # Script templates and boilerplates
└── README.md        # This file
```

## Organization

### scripts/
Contains working scripts organized by purpose or technology:
- Place your completed, working scripts here
- Consider organizing into subdirectories by language or purpose (e.g., `python/`, `javascript/`, `bash/`)

### templates/
Contains reusable script templates and boilerplates:
- Store template files that can be copied and modified for new scripts
- Include starter code and common patterns

## Usage

### Adding a New Script

1. Place your script in the appropriate directory under `scripts/`
2. Add a brief comment or header explaining what the script does
3. If it's a new type of script, consider creating a template in `templates/`

### Best Practices

- **Documentation**: Add comments explaining what each script does
- **Naming**: Use descriptive names for scripts (e.g., `convert-json-to-csv.py`)
- **Headers**: Include a brief description at the top of each script
- **Dependencies**: Document any required libraries or tools

## Contributing

Feel free to add, modify, or organize scripts as needed. Keep scripts general-purpose and non-project-specific.
